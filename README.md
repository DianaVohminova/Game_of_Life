# Game_of_Life

Программа реализует "Игру в жизнь". 
Задается начальное состояние, на примере файлов конфигураций, размещенных в папке src/datafiles
после запуска программы происходит симуляция.

Для изменения скорости симуляции восполььзуйтесь клавишами
A/a - для уменьшения скорости симуляции
Z/z - для увеличения скорости симуляции

## Компиляция и запуск
В папке src
gcc game_of_life.c -o game
./game datafiles/glider.txt // запуск с начальной конфигурацией glider
